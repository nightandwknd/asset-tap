# The original lines below label the wasm memory figure "peak RSS VmHWM=... (wasm linear memory)".
# That label is WRONG. On wasm32-wasip1 there is no /proc and no RSS. The number is the SIZE OF WASM
# LINEAR MEMORY (pages * 64 KiB) read at program exit. It is not resident-set size and not a measured
# peak of live data (linear memory only grows and the allocator may retain unused pages). It is not
# comparable with the native "peak RSS VmHWM" values in native-timings.txt, which really are the
# kernel's peak resident set. native-probe/src/main.rs now prints the corrected label; a re-run of the
# smallest fixture printed the identical number (17600 kB), so only the label changed, not the data.
